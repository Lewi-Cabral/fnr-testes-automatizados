# Projeto de Testes Automatizados - FNR Controle de Vendas

Este repositório contém o projeto de testes manuais e automatizados desenvolvido para a disciplina de Testes de Software. O objetivo é validar as funcionalidades do sistema "FNR Controle de Vendas".

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Python 3.11
- **Framework de Testes:** Pytest
- **Automação Web:** Selenium WebDriver
- **Relatórios:** PDF (Plano e Projeto de Teste)

## 📂 Estrutura do Projeto

- `test_fnr_final.py`: Script contendo os 10+ cenários de testes automatizados (fluxo feliz e exceções).
- `Plano_de_Teste.pdf`: Documento detalhando a estratégia e o planejamento dos testes.
- `Projeto_de_Teste.pdf`: Documento com os resultados das execuções e evidências (screenshots).

## 🛠️ Como Executar os Testes

1. Certifique-se de ter o Python instalado.
2. Instale as dependências:
   ```bash
   pip install selenium pytest webdriver-manager
   ```
3. Execute os testes:
   ```bash
   pytest test_fnr_final.py
   ```
